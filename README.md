# Retail Performance Intelligence Dashboard — End-to-End Excel Analytics

## Project Overview

This project is an interactive Excel Sales Analytics Dashboard created using supermarket sales data. The dashboard is designed to provide dynamic business insights through KPI cards, Pivot Tables, Pivot Charts, slicers, and report connections.

The project focuses on analyzing sales performance, profitability, customer behavior, product performance, payment trends, and time-based sales patterns using Microsoft Excel.

---

* Interactive KPI Cards

* Report Connections
* Revenue & Profit Analysis

## Dataset Information

The dataset contains supermarket transaction records including:

* Sales
* Profit
* Product Categories
* Customer Information
* Payment Methods
* Ratings
* Date & Time Information

The workbook includes approximately 1,000 transaction records used for analysis and dashboard creation.

---

## Workbook Structure

### 1. Raw Dataset

Contains the original supermarket sales data.

### 2. KPI Backend

Backend Pivot Tables and calculations used to power the dynamic dashboard.

### 3. Dashboard

Interactive Excel dashboard with slicers and KPI cards.

### 4. Business Insights Report

Contains summarized analytical findings and business insights.

### 5. Analysis Sheets

Separate sheets created for:

* Revenue by City
* Product Line Performance
* Monthly Profit Trends
* Payment Method Analysis
* Customer Type Analysis
* Pricing & Rating Analysis
* Sales by Time Period
* Product Profitability Analysis
